What access allows

Enabling access opens a dedicated window. Agents on this Muxterm account can read signed-in sites, screenshot, type, and submit forms inside it.

The window shares your Chrome profile’s sign-ins and permissions. Use a separate Chrome profile for stronger separation. Other windows are outside agent control.

Access stays on until paused. Browser restarts leave it paused. Chrome shows a debugging banner while access is active.

Add Muxterm

Connect to Muxterm

Pairing does not enable browser access.

Remove Muxterm?

This stops browser access and deletes its saved URL and pairing from this browser. It does not revoke the connection on the server.
