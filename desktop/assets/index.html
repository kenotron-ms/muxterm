Muxterm for Mac

Run the full muxterm app in a Mac window. Its Browser panel opens previews at their real localhost URLs.

Connection

Local port forwards

Forward a dev server's port from your SSH host to the same port on this Mac. Pages keep their root path and localhost origin.

SSH key access must already work from this Mac. Try ssh my-devbox once in Terminal if the forward cannot connect.

Browser tab

Open a page in muxterm's right-side browser panel. A localhost port automatically forwards from the SSH host.
