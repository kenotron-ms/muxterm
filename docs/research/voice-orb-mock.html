before / after — same metric, same browser, same harness

Continuity measured as velocity, not per-frame delta: a dropped frame is not a discontinuity, and dividing by the frame's own dt removes that confound. Reported as a multiple of the average rate the transition needs (range / 420ms). The steepest point of the easing curve is 2.73; a true jump — the whole range inside one 16.7ms frame — is about 25. Range is measured empirically in both cases: the band the rendered box occupies while each state is settled. rect is getBoundingClientRect, which is the only honest reading — getComputedStyle().transform omits the independent scale property, which is exactly what the old orb animated.
