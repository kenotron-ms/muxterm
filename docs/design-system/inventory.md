## Fixed feature dimensions

The `literalDimensions` baseline in `web/scripts/ui-legacy-baseline.json` is
zero for every component. The gate also scans static inline style attributes,
which previously hid fixed spacing in Settings Notifications. Positive pixel or
rem values in width and height declarations must use named design tokens. Chat
and Utility retain their own layout structure, but their bounds are explicit
tokens in `tokens.css`.
Responsive breakpoints, grid proportions, and editor behavior are reviewed in
their screen stories and the live app.

- The old Connect machine overlay and its launcher entry were removed after the active UI stopped emitting `connect-machine`. Settings → Remotes remains the reachable remote-host setup path.

## Catalog coverage

The catalog has stories for the shared UI elements and the primary current
screen components. `mux-app` has no standalone Storybook story because it owns
the live WebSocket/sessiond lifecycle; its constituent screens have stories and
the app shell must be reviewed in dev-local. `mux-browser-assistant` is included
because it is a screen introduced on main after the earlier catalog branch.

The unreachable legacy launcher menu and Connect machine overlay were removed
with their Storybook stories. Remote host actions remain in Settings → Remotes.
The Sidebar's old workspace-preview and machine-group code was removed because
the current render path did not call it. The historical unit-test fixture is
skipped; current navigation and workspace creation are verified in Chromium.
