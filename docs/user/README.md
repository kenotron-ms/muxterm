# Muxterm user guide

Start an AI conversation, give agents tasks to work on, and check their progress from the same workspace.

## Start here

- [Set up Muxterm](installation.md) to install the app and connect an AI agent.
- [Start your first chat](first-chat.md) to choose an agent, give it some context, and open project files beside the conversation.
- [Delegate and review work](work.md) to hand a task to another agent and check what it delivers.

## Keep working

- [Open Muxterm on another screen](remote-projects.md) to check in from your phone or reach a project on another computer.
- Open **Terminal** from the sidebar when you need to run a command. You can return to the same terminal after closing the browser tab.
