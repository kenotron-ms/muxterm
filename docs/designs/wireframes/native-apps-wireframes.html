muxterm — Native Companion Apps: Low-Fidelity Wireframes

This page is a static, low-fidelity wireframe set for the muxterm native companion apps (macOS/desktop, iOS/Android phone, tablet). It complements the design documents in docs/designs/ — specifically the native companion apps design and the browser pane / session architecture designs. These are grayscale, boxy layout sketches only: no branding, no color, no production chrome. Dashed boxes are content placeholders.

Guiding principle: the tool should feel the same every launch — a unified dashboard grouped by source (Local / remotes), regardless of which device you open it from.
● = connected ○ = disconnected ▩ = pane-count badge ▾ / ▸ = expanded / collapsed group dashed box = content placeholder monospace = terminal area
