Do this once

  1. Install this page. Chrome menu (⋮) → Add to Home screen / Install app. Then close Chrome and open it from the new icon. Skipping this tests a browser tab, not an installed PWA — and that difference is the whole question. The badge at the top of this page says which one you are in right now.
  2. Tap START. Allow the microphone when asked.
  3. You will hear a soft tone. That is deliberate and required — a silent audio track does not count as "playing audio" to Chrome. Turn the volume down. Do not mute.
  4. Say something. Check that both bars below move. If the mic bar never moves, stop and fix that first.
  5. Press the power button so the screen goes off. Put the phone down.
  6. Wait 15 minutes. Do not touch it, do not open another app.
  7. Wake the screen and open this page again (from the same icon, or just unlock if it is still on screen).
  8. Read the VERDICT. Then tap Copy report and paste it wherever you keep notes.
